# Pasta de Assets Brutos (assets/raw)

Coloque aqui os arquivos brutos exportados da IA ou referências conforme a lista da imagem:
- `eirik_idle_01.jpg`
- `eirik_walk_passing.jpg`
- `eirik_walk_01.jpg`
- `eirik_run_01.jpg`
- `eirik_jump_01.jpg`
- `eirik_attack.jpg`
- `axe_slash_vfx.png`

Depois de colar as imagens nesta pasta, o script `scripts/clean_sprites.py` irá pré-processá-las automaticamente e salvar os PNGs transparentes de 80x80 na pasta `public/sprites/`.
